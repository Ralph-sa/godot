# M20 渲染能力 Spec（基于代码核对 2026-08-17）

## 代码事实
- 当前渲染方法：gl_compatibility（GLES 3.0 上下文）——2D 完整、
  3D 基础渲染可用（无 SDFGI/volumetric fog/TAA 等 forward+ 特性，
  这是渲染器本身限制，与移植无关）
- forward_plus/mobile（Vulkan）：模拟器禁用（转译层崩溃）、
  Maleoon compute 失败冻结（M06）
- **渲染画面在模拟器不可见**（express_gpu 不刷新帧）——渲染正确性无验证环境

- ③ 2D 场景渲染调用链完整（canvas renderer 无断言）
