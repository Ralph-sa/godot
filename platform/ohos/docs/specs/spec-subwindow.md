# M10 子窗口与多窗口 Spec

## 目标
编辑器子窗口（脚本编辑器独立窗口、浮窗）在鸿蒙上的创建与输入分发。

## 现状
- 子窗口生命周期（NAPI 桥 handleSubWindow）已实现。
- 输入事件分发到子窗口未实现（当前全部注入主窗口）。

## 验收标准
- ① 子窗口创建/调整/关闭 NAPI 桥正确
- ② 子窗口区域的触摸路由到对应窗口 ID
- ③ 验证：引擎请求创建子窗口 → 原生窗口出现（模拟器自由窗口模式）

## 剩余任务
- [ ] T-SW-1 子窗口输入分发（坐标判断窗口归属）
- [ ] T-SW-2 模拟器验证子窗口创建链路

## 开放项
- 模拟器 express_gpu 不刷新帧——子窗口画面不可见，只能验证窗口管理 API 调用成功。
